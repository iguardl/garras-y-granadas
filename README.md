# Garras y Granadas

Juego por turnos de animales largos con física, armas y tierra que se rompe. De 2 a 8 equipos, en la misma compu o en línea.

## Descargar

Baja el instalador de la **[última versión](https://github.com/iguardl/garras-y-granadas/releases/latest)** (`GarrasYGranadas_..._x64-setup.exe`) y ábrelo. Es para Windows 10/11.

El juego se actualiza solo: cuando hay versión nueva, te avisa al abrirlo.
